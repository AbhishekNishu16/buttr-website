# Launch checklist

Things only you and Ajay can decide or provide. Tick them off before the site goes public.

## Accounts

* [ ] Domain bought, and access to its DNS settings
* [ ] GitHub account and private repository
* [ ] Vercel account (or your chosen host)
* [ ] Claude Platform account with billing, an API key and a monthly spend limit
* [ ] Claude Code installed, or the Claude desktop app with the Code tab

## Decisions

* [ ] Where meeting requests and Pocket Buttr sign ups go (email inbox, Google Sheet, CRM)
* [ ] Who replies to a lead, and how fast
* [ ] WhatsApp Business number, or keep the icon hidden
* [ ] Analytics tool
* [ ] Which model answers questions, after the question test

## Licences and rights

* [ ] Commercial webfont licence for Canela Deck (the files here are trial cuts)
* [ ] Rights to every photo on the site (people, partners, founders)

## Compliance (Ajay)

* [ ] Regulatory wording: mutual fund distributor, AMFI registration, SEBI, suitability
* [ ] ARN and the standard mutual fund disclaimer in the footer, as required
* [ ] Calculator assumptions confirmed or replaced (idle cash, tax, hidden costs, loans, deposits)
* [ ] The "2 to 3% a year" cost line
* [ ] Partner profile numbers (families per partner)
* [ ] Privacy policy and terms, in line with India's data protection law
* [ ] Consent wording on the meeting form

## Final checks

* [ ] Every answer on a real iPhone and Android phone
* [ ] Both themes
* [ ] Question test passed
* [ ] Lighthouse 90 or above
* [ ] Spend limit and rate limit working
